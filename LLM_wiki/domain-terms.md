# Domain Terms

> 정의 위주. 연도별 수치(요율·단가)는 여기 적지 않는다 — `data/prices/` + `data-sources.md`.
> 확인 수준 표시: (확인) 공식 자료로 검증됨 / (일반) 업계 일반 개념, 세부는 출처 확인 필요.

## CAD / BIM 포맷

- **DWG** (일반): Autodesk AutoCAD의 독점 바이너리 포맷. 버전 코드(AC1027=2013, AC1032=2018 등)로 구분. 직접 읽기 어려워 보통 로컬 변환(ODA File Converter 등)으로 DXF로 바꾸거나 상용/오픈 라이브러리를 쓴다 — 라이브러리 선택은 ADR 대상.
- **DXF** (일반): Autodesk가 공개한 교환 포맷(텍스트/바이너리). 그룹 코드 기반. Python `ezdxf`로 읽기 쉬움.
- **IFC** (일반): buildingSMART의 개방형 BIM 표준(ISO 16739). 객체가 의미(IfcWall, IfcDoor, IfcSlab…)와 속성 세트(Pset_*), 수량 세트(Qto_*BaseQuantities)를 가질 수 있다. Python `ifcopenshell`.
- **RVT** (일반): Autodesk Revit 독점 포맷. 외부에서 직접 읽기 어려움 — 보통 Revit에서 IFC로 내보내 처리.
- **2D vs 3D**: 2D 도면(DWG/DXF)은 선·블록·텍스트일 뿐 "벽"이라는 의미가 없다 → 레이어·블록 이름 관례로 의미를 추론해야 함(매핑 규칙 필요). 3D BIM(IFC)은 객체 의미와 수량이 들어 있을 수 있어 물량산출이 훨씬 직접적.

## CAD 구성 요소

- **엔티티**: 도면 객체. LINE, LWPOLYLINE/POLYLINE, ARC, CIRCLE, HATCH(채움 — 면적 산출 단서), TEXT/MTEXT, DIMENSION, INSERT 등.
- **handle**: 엔티티 고유 ID(16진 문자열). 추적성의 기본 키.
- **레이어(Layer)**: 엔티티 분류. 관례 예: `A-WALL`, `A-DOOR`, `E-LITE`(전기 조명), `M-DUCT`. 작성자마다 다름. 국내 표준 레이어 체계 존재 여부는 조사 대상.
- **블록(Block) / INSERT**: 재사용 심볼 정의 / 그 배치. 문·창·조명·콘센트·위생기구 등이 보통 블록 → **개수 산출의 핵심**. 중첩 블록, MINSERT(배열), 동적 블록 주의.
- **ATTRIB / ATTDEF**: 블록에 붙은 속성값(규격·타입 등) — 규격 매핑의 핵심 근거.
- **XREF**: 외부 참조 도면. 참조 파일이 없으면 내용이 빠짐.
- **Model space / Paper space(Layout)**: 실제 형상 / 출력용 배치. 뷰포트 때문에 같은 객체를 두 번 세기 쉬움.
- **$INSUNITS**: 도면 단위 헤더 변수(4=mm, 6=m 등). 비어 있거나 틀린 경우가 많다.
- **축척**: 1/100 등. 2D 도면에서 실제 길이 환산 시 확인 필요.

## 적산·견적 (한국 건설)

- **적산(積算)** (일반): 설계도서로부터 공사비를 산출하는 일 = 물량산출 + 단가 적용.
- **물량산출 / 수량산출서 (QTO, Quantity Take-Off)**: 도면에서 공종·품목별 수량을 뽑은 문서.
- **내역서 (BOQ, Bill of Quantities)**: 공종·품목·규격·단위·수량·단가·금액 표.
- **견적서**: 발주처/고객에게 제출하는 금액 문서(내역서를 포함하거나 요약).
- **설계수량(순수량) / 할증**: 도면상 정미 수량 / 절단·손실 등을 고려한 추가율. 할증률은 표준품셈에 품목별로 규정(수치는 연도별 출처 확인).
- **표준품셈** (일반): 공종별 단위작업당 재료·노무(인공)·장비 투입량 기준. 공공공사 예정가격 산정의 기준. 매년 개정. 일반 건설 부문은 국토교통부가 정하고 한국건설기술연구원이 관리한다(일반).
- **전기공사 표준품셈** (확인, docs/research/2026-11-09_elec-pumsem-rounding-workflow.md): 발행처는 **대한전기협회**이며 국토교통부가 아니다(D-015). 이용조건 본문은 미확인이므로 수치를 저장소에 옮기지 않는다(operating-rules 규칙 13).
- **예정가격작성기준** (일반): 예정가격 산정 기준 계약예규. **예규 번호·시행일·소관 부처는 재확인 필요**(D-016). 문서마다 다르게 표기돼 있다(기획재정부 제785호 2025-05-01 vs 재정경제부 제171호 2026-08-25 시행). 확정 전 인용할 때는 "번호 재확인 필요"를 붙인다.
- **일위대가(一位代價)**: 단위 작업 1단위당 재료비+노무비+경비 단가. 품셈 × 단가로 만든다.
- **표준시장단가**: 과거 공사 계약단가 기반의 공종별 단가(공공).
- **시중노임단가**: 대한건설협회가 정기 공표하는 직종별 노임(반기 단위로 알려짐 — 확인 필요).
- **자재 단가 출처**: 조달청 가격정보, 물가정보지(예: 한국물가정보 「종합물가정보」, 한국물가협회 「물가자료」), 견적 단가(업체 견적). 세부·이용조건은 `data-sources.md`.
- **원가계산서** (일반): 재료비 + 노무비(직접·간접) + 경비(산재·고용보험료, 안전관리비 등) + 일반관리비 + 이윤 + 부가가치세. 요율은 법령·고시로 정해지며 해마다 변동 → 출처 확인 필수.
- **공공 원가계산 방식 vs 민간 실행견적**: 전자는 품셈·고시 요율 기반 예정가격 구조, 후자는 업체의 실제 자재·인건비·마진 기반. 어느 쪽인지 `docs/decisions.md`에서 정한다.

## 공종 (Trade)

- 건축(골조·마감·창호·수장), 전기(조명·전열·간선·통신), 기계설비(급배수·위생·냉난방·덕트), 소방, 인테리어. 공종마다 도면·레이어·블록 관례와 산출 단위가 다르다 → MVP는 한 공종부터.
