# 적산 기준·단가 출처 조사 (2026-11-09)

작성: bim-researcher / 리서치 루프 사이클 2. 조사 방식: WebSearch + WebFetch(공개 페이지만, 로그인·결제 없음).
한계: 이 환경에서 PDF 본문을 텍스트로 추출하지 못했다(바이너리 반환). 따라서 **PDF 안의 숫자(할증률 표, 직종별 노임, 제비율 표)는 이번에 직접 확인하지 못했다.** 위치만 기록한다.

## 질문
1. 표준품셈: 발행·관리 기관, 2026년판 위치, 형태, 이용 조건, 재료 할증률 규정 위치
2. 시중노임단가: 공표 기관·주기·최신 시점·다운로드 형태
3. 자재 단가: 조달청 가격정보, data.go.kr API, 물가정보지(한국물가정보/한국물가협회), 표준시장단가 위치
4. 원가계산 제비율 근거 법령·고시 위치
5. 공공 원가계산 vs 민간 실행견적, 내역서 표준 공종 코드

## 결론 요약
- (확인됨) 2026년 적용 표준품셈·표준시장단가는 국토교통부가 2025-12-23 공고, 2026-01-01 적용. 열람처는 국토부 누리집 / 한국건설기술연구원(KICT) 공사비원가관리센터(cost.kict.re.kr). 다만 2026 원문 파일의 정확한 메뉴·형태(PDF/엑셀)는 직접 확인 못 함(불확실).
- (확인됨) 시중노임단가는 대한건설협회(CAK)가 반기 공표. 최신은 2026년 하반기(2026-09-01 공표·적용), PDF 보고서가 로그인 없이 CAK 사이트에서 다운로드된다. 직종 132개, 일 평균 282,737원(뉴스 보도).
- (확인됨) **무료·공식 API 존재**: 공공데이터포털 "조달청_나라장터 가격정보현황서비스"(시설공통자재 토목/건축/기계설비/전기·정보통신, 시장시공가격, 표준시장단가 등 11개 오퍼레이션, 무료, 이용허락 제한 없음). 조달청 시설자재 가격은 연 2회 갱신(최근 2026-10-01 발표, 6,584개 품목). 이것이 MVP 단가 경로의 핵심이다.
- (확인됨/불확실) 물가정보지(한국물가정보·한국물가협회)는 유료 간행물. 온라인 요금·API는 공식 페이지에서 못 찾음 = "없음"이 아니라 "못 찾음".
- (유력) 제비율은 기획재정부 계약예규 「예정가격 작성기준」(제785호, 2025-05-01 시행), 국가계약법 시행규칙, 조달청 「공사원가계산 제비율(간접공사비) 적용기준」, 고용노동부 산업안전보건관리비 고시에 근거. 연도별 수치는 이번에 1차 확인 못 함.
- (유력) 민간 시공사는 공공 원가계산 구조를 의무로 따르지 않고 사내 양식 + 실행예산을 쓴다. 단 조달청 표준공사코드(공사원가통합관리시스템)가 공공 내역서의 코드 체계로 공개돼 있어 품목 매핑의 기준으로 쓸 수 있다.

## 무료로 MVP를 만들 수 있는 단가 경로 (추천안 — 결정은 planner/CEO)
1. **재료 단가**: A(조달청 가격정보현황서비스 API)를 1순위 어댑터로. 조회 결과를 `data/prices/`에 스냅샷(기준일·`게시일자`·`부가가치세포함여부`·API 응답 시각 저장)으로 캐시. B의 CSV는 오프라인 폴백.
2. **노무 단가**: C(CAK 시중노임 PDF)를 반기별로 사용자가 내려받아 `data/prices/`에 구조화(수기 또는 파서). 출처에 "대한건설협회 2026 하반기 임금실태조사, 2026-09-01" 기록.
3. **품목 코드**: 조달청 표준공사코드(#14, 세부공종코드·자원코드)를 품목/규격 매핑의 기준 키로 채택 검토 → 내역서 코드 체계로 사용 가능.
4. **할증률**: 표준품셈 공통부문 제1장 "재료 및 노임의 할증" 표를 사용자 지정 판(연도)으로 입력받아 수기 구조화. 품셈 항목에 이미 할증이 포함된 경우 중복 적용 금지 규칙 필요(#6).
5. **매핑 못 한 품목**은 `UNPRICED`. 물가정보지 값이 필요하면 사용자가 수기로 입력(`QUOTE`/수기 출처 필드).
6. **제비율**: MVP에서는 직접공사비(재료+노무) 집계까지만 하고, 간접공사비·일반관리비·이윤은 연도별 조달청 제비율 원문 확인 후 **사용자 입력 파라미터**로 받는다(코드에 숫자 하드코딩 금지).

## 유료가 필요해지는 지점
- 조달청 가격에 없는 **시중 실거래 가격**(브랜드 자재, 전기 기자재, 소량·수입품 등) 커버리지가 부족해질 때 → 물가정보지(종합물가정보/물가자료) 구독 또는 업체 견적. 프로그램에서 자동으로 받으려면 **재배포·자동수집 약관 확인과 별도 계약**(API 제공 여부 자체는 못 찾음)이 필요.
- 표준품셈을 **엑셀·DB 형태로 구조화해 제공하는 상용 적산 소프트웨어/데이터**를 쓰고 싶을 때(이번 조사 범위 밖, 제품은 미조사).
- 정식 대량 호출용 운영 계정은 무료 신청으로 확대 가능하다고 되어 있으나(#17 유형), 가격정보 API의 한도는 미확인.
- 위 모두 AGENTS.md상 **결제·가입·약관 동의는 사용자 확인 사안**(CEO 불가).
