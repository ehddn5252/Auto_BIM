# 공개 샘플 도면 · MVP 공종 · 경쟁 제품 조사 (2026-11-09)

작성: bim-researcher / 리서치 루프 사이클 3. 도면 다운로드는 하지 않았고 위치만 정리했다.
표기: 확인됨(1차 출처를 직접 열어봄) / 유력(2차 또는 일부만 확인) / 불확실.

## 질문
1. 개발·테스트에 합법적으로 쓸 수 있는 공개 DWG/DXF/IFC 샘플은 어디에 있나? 공공 발주 설계도서(도면+내역서 쌍)는 구할 수 있나?
2. MVP 공종은 무엇이 좋은가(블록 개수 기반으로 잘 뽑히는 공종 vs 어려운 공종)?
3. 유사·경쟁 제품은 무엇이고 시사점은?

## 결론 요약
- 공개 샘플 IFC는 있다(확인됨). 그러나 **도면(DWG)+정답 내역서 쌍으로 공개된 합법 샘플은 이번 조사에서 못 찾았다**(불확실, "없음"이 아님). 나라장터는 설계도서를 전자열람하는 제도가 있으나 대상·자격·파일 형식은 현재 기준으로 확인하지 못했다.
- 공개 2D DWG/DXF 중 **전기·설비 적산용으로 라이선스가 명확한 것**은 거의 없다. 따라서 개발 초기 테스트는 (a) ezdxf로 직접 합성한 DXF(블록 개수 정답을 우리가 알고 있음) + (b) buildingSMART IFC 샘플로 하고, 실제 정확도 검증은 사용자가 구하는 실도면을 기다려야 한다(유력).
- MVP 공종은 **전기(조명·콘센트·스위치 등 기구 개수) 1안**, **건축 개구부(문·창호 개수·면적) 2안**을 추천. 길이(배관·배선·전선관)는 경로·높이·할증 때문에 2단계 이후(유력).
- 경쟁: 해외는 PDF/래스터 기반 AI 카운트가 보편적이고, 국내는 포비콘이 DWG 직접 분석(골조 중심)으로 가장 가깝다. 우리 차별점은 **DWG 블록/레이어 근거 추적성 + 국내 내역서 양식 + 로컬 처리(기밀)**(유력, 시사점은 추론).

## 선택지 비교: MVP 공종
| 안 | 범위 | 장점 | 단점/위험 |
|---|---|---|---|
| 1안 전기 | 조명·콘센트·스위치·분전반 등 기구 개수 (+ 가능하면 폴리라인 길이는 "참고값"으로 분리) | 블록 개수 중심이라 근거 추적이 쉬움(handle로 되돌아감). 범례 대조로 검증 가능. 해외 상용이 같은 단위 자동화 → 수요 검증 | 도면마다 블록명·레이어 규칙 상이 → 매핑 UI 필요. 배선 길이는 제외하면 내역서 일부만 채움 |

## 확인 못 한 것 / 추가 조사 필요
- 나라장터 설계서 전자열람의 현행 대상 범위, 로그인·자격 요건, 파일 형식(DWG 여부), 재이용 조건.
- LH·지자체의 설계도서 공개 방식(전자조달 ebid.lh.or.kr, cotis.lh.or.kr 등)은 열람 방법 미확인.
- buildingSMART 저장소 폴더 내 건축·MEP 파일 목록, Duplex 이용 조건 원문.
- 국내 일반 적산 프로그램(제품명·가격·CAD 연동), 포비콘 가격·공종 범위, CostX 현재 가격.
- 공종별 자동화 수요에 대한 정량 자료.
- 외부 가격 수치는 모두 2차 출처이므로 "현재 시세"로 단정하지 않는다.

- bim-ceo: (1) MVP 공종 1안(전기)/2안(건축 개구부) 선택, 사용자 업무 분야가 알려지면 그에 맞춤. (2) 샘플 확보 전략: 합성 DXF + 공개 IFC로 개발, 정확도 검증은 사용자 실도면 대기. (3) 나라장터 등에서 계정·인증서가 필요한 경우 사용자 결정 사항.
