## 2. 대상 사용자 (페르소나)

### P1. 적산 담당자 (주 사용자, D-001)

- **소속 예**: 전기공사업체 또는 종합건설사의 적산·견적 담당. MVP 공종이 전기 기구(D-003, 잠정)이므로 전기 도면을 받아 수량을 뽑는 사람을 기준으로 둔다.
- **목표**: 받은 도면 세트에서 기구별 수량을 빠르고 틀림없이 뽑아 자기 내역서에 옮긴다. 나중에 "이 숫자 어디서 나왔냐"는 질문에 답할 수 있어야 한다.
- **지금 하는 일 (추론, 사용자 확인 필요)**: 실무 흐름을 1차 자료로 조사한 결과는 아직 없다. 아래는 도메인 일반 지식과 조사 문서의 정황(학회 자료의 "수작업 카운트")에서 추론한 것이다.
  1. 도면 세트(DWG 또는 PDF)를 받는다. 전기 도면은 층별·용도별(전등, 전열, 동력)로 나뉜다.
  2. 범례(기호표)를 보고 기호와 품명·규격의 대응을 파악한다.
  3. 층별로 기호를 센다. 종이나 PDF에 체크 표시를 하거나, CAD의 선택·개수 기능을 쓴다.
  4. 엑셀 수량산출서에 층별·품목별 수량과 산출 근거를 적는다.
  5. 내역서 품목(품명·규격·단위)에 대응시키고, 단가(조달청 가격, 물가지, 견적)와 노무비(품셈 × 노임)를 붙인다.
  6. 사수나 팀장이 검토한다. 누락, 중복, 범례 기호를 잘못 센 경우가 대표적인 지적 사항이다(추론).
- **불편 (추론)**: 반복 카운트에 시간이 들고, 누락·중복 위험이 있으며, 근거 정리가 번거롭다. 도면이 개정되면 다시 세야 한다.
- **이 도구에 바라는 것**: 3~4단계를 대신 해 주고, 1EA 단위로 근거를 남겨 주며, 확신이 없는 것은 따로 모아 보여 주는 것. 최종 판단은 담당자가 한다.
- **기술 수준 가정**: AutoCAD 같은 CAD에서 "다른 이름으로 저장 → DXF"를 할 수 있고 엑셀을 능숙하게 다룬다. 명령줄과 텍스트 규칙 파일을 편집하는 능력은 **확인되지 않았다**. D-011은 이 형태로 개발을 진행하되 수용 여부를 사용자에게 확인하기로 했다(잠정).

### P2. 검토자 (보조 사용자)

- 담당자의 수량산출서를 검토하는 사수나 팀장이다. 도구를 직접 실행하지 않고 xlsx 산출물만 본다. 따라서 산출물만 보고도 근거와 미확인 항목을 판단할 수 있어야 한다.

### 대상이 아닌 사람

- 설계자(도면 수정·검토), 발주처의 예정가격 확정 업무, 일반 소비자 견적.

## 3. 유저 저니 (MVP, to-be)

```
[0 준비] → [1 입력] → [2 사전 점검] → [3 결과 검토] → [4 매핑 수정·재실행] → [5 수량산출서] → [6 내역서(직접공사비)] → [7 자기 내역서에 반영]
```

| 단계 | 담당자 행동 | 시스템 동작 | 산출물 / 표시 | F-ID |
|---|---|---|---|---|
| 0 준비 | 받은 DWG를 자기 CAD에서 DXF로 저장한다(D-002 기본 경로). 도면이 DXF로 왔으면 그대로 쓴다 | — | — | F-011 |
| 1 입력 | 도면 세트(DXF 1개 이상)와 매핑 규칙 파일, 품목 사전을 지정해 실행한다. 원본이 DWG이면 저장에 쓴 CAD 이름과 버전을 적는다(선택) | 파일 해시와 변환 이력을 기록한다 | 실행 기록 | F-001, F-011 |
| 2 사전 점검 | 경고를 읽는다. 단위를 모르면 직접 지정하고 다시 실행한다 | 단위를 판정한다. XREF, `*U`, ACIS, UNDERLAY, PROXY 같은 미지원 요소를 경고한다. 범례로 의심되는 영역을 경고한다 | 경고 목록. 단위 미확정이면 수량을 내지 않는다 | F-002, F-003 |
| 3 결과 검토 | 품목별 수량을 범례·도면과 대조한다. 의심 가는 수량은 handle과 좌표로 CAD에서 찾아본다 | 블록을 집계하고, 제외 규칙을 적용하고, 매핑한다 | 품목별 수량(층별 소계), 근거 handle, 제외 목록(사유별), UNMAPPED | F-004~F-009 |
| 4 매핑 수정 | UNMAPPED를 보고 규칙 초안 파일에 품목 ID를 채운다. 범례 영역이나 제외 레이어를 규칙에 넣고 다시 실행한다 | UNMAPPED를 규칙 초안 형태로 내보낸다. 규칙 파일 해시를 기록한다 | 규칙 초안, 재실행 결과 | F-007, F-014 |
| 5 수량산출서 | xlsx를 열어 검토하고, 검토자에게 넘긴다 | 수량산출서를 생성한다(요약, 산출근거, handle, UNMAPPED, 제외, 경고, 실행정보) | `수량산출서.xlsx` (검토용 초안 표시) | F-010 |
| 6 내역서 | 단가 스냅샷의 기준일을 확인한다. UNPRICED 품목은 자기 자료로 채운다 | 자재 단가는 조달청 CSV 스냅샷, 노무비는 품셈 인공 × CAK 노임에서 근거가 있을 때만 적용한다. 출처가 없는 성분은 UNPRICED로 둔다 | `내역서.xlsx` (직접공사비까지, 재료/노무/경비 분리) | F-015~F-018 |
| 7 반영 | 자기 내역서에 옮긴다. 원가계산서는 MVP에서 만들지 않는다(D-007) | — | — | — |

**저니 설계 원칙**

- 시스템은 숫자를 조용히 버리거나 0으로 채우지 않는다. 각 단계의 "모름"은 다음 단계 산출물까지 그대로 따라간다.
- 사람의 수정은 규칙 파일을 통해서만 반영한다. 산출된 xlsx를 손으로 고친 내용은 재실행 시 재현되지 않으므로, 고칠 곳은 규칙 파일이라고 안내한다.
- 모든 산출물에는 "검토용 초안" 표시를 붙인다. 확정본 내보내기는 Gate 3 대상이며 MVP 범위가 아니다.

## 4. MVP 범위

### 4.1 입력

- **포맷**: DXF만 받는다(D-002). DWG는 사용자가 자기 CAD에서 DXF로 저장한다. 변환 어댑터는 인터페이스와 이력 기록만 두고, MVP에서 동작하는 어댑터는 "사용자 저장(수동)" 하나다.
- **단위**: 1회 실행에 같은 세트의 DXF 1개 이상. 파일(층)별 소계와 세트 합계를 낸다.
- **공간**: 모델스페이스만 집계한다. 페이퍼스페이스 객체는 제외 목록에 사유와 함께 남긴다.

### 4.2 공종·대상 (D-003 잠정)

- 전기 기구 개수(EA): 조명기구, 콘센트, 스위치, 분전반.
- 집계 근거는 블록 INSERT(MINSERT 포함)뿐이다. 선이나 원으로 그린 기호는 세지 않고 "블록 아닌 기호 의심"으로 경고한다.
- 공종이 바뀌어도(D-003의 전환 조건) 바뀌는 것은 매핑 규칙과 품목 사전 데이터뿐이다. F-001~F-014는 공종과 무관하게 정의한다.

### 4.3 출력 (D-007, 출력 양식 v1: D-008 Q4)

- **출력 양식 v1**: 수량산출서 7시트 구성과 내역서 열 구성(D-007 열 + 성분별 상태·출처·근거)을 승인받았다(D-008). 사용자의 실제 수량산출서를 받으면 재검토한다.
- **수량산출서 xlsx**: 순수량, 근거 handle 포함. 요약 시트 맨 위에 UNMAPPED·CONFLICT·경고 건수, 그리고 숨김 레이어(동결·끔) 제외 건수가 1개 이상이면 그 건수를 표시한다(D-009 Q3).
- **내역서 xlsx**: 직접공사비까지. 품목, 규격, 단위, 수량, 재료비·노무비·경비 단가와 금액, 출처, 도면 근거.
- 원가계산서는 만들지 않는다. 견적 방식이 확정된 뒤 F-019로 다룬다.

### 4.4 단가 (D-005, D-006)

- **자재**: 조달청 공공데이터 CSV 스냅샷(시설공통자재 15083244, 표준시장단가 15151298)을 쓴다. API 어댑터는 인터페이스만 정의한다.
- **노임**: CAK 2026 하반기 시중노임(2026-09-01 적용) PDF를 구조화한다.
- **노무비**: "품셈 투입인공 × 노임"으로 추적할 수 있을 때만 낸다. 전기공사 표준품셈의 이용조건을 확인하기 전에는 UNPRICED로 둔다. **따라서 MVP 내역서의 노무비 열은 당분간 대부분 UNPRICED일 것으로 예상한다.**
- **품목 코드**: 내부 품목 ID를 쓰고, 조달청 표준공사코드는 참조 속성으로 붙인다.
- **제비율**: 기본값 없는 사용자 입력 파라미터다. MVP는 원가계산서를 만들지 않으므로 쓰지 않는다.

### 4.5 사용 형태 (D-011, 잠정)

- 로컬에서 실행하는 명령 하나와 파일 산출물(xlsx), 사람이 편집하는 규칙 파일로 개발한다. GUI는 MVP 비목표다.
- 이 형태가 P1의 기술 수준에 맞는지는 사용자 확인 대기다(CEO 경유). 수용하지 않으면 코어는 유지하고 입출력 계층만 바꾼다(예: 규칙을 xlsx 표로 편집). 그래서 F-007의 규칙 내용(조건·결과·우선순위)은 파일 형식과 독립적으로 정의한다.

### 4.6 단위 지정 (D-010)

- 단위를 모르는(`UNIT_UNKNOWN`) 파일에 담당자가 단위를 지정하면 수량을 낸다. 지정 사실(판정 출처 `user`)은 실행정보와 경고 시트에 남고, 헤더 값과 다르면 `UNIT_OVERRIDE` 경고가 붙는다.
- 시스템이 좌표 범위로 추정한 단위는 수량 산출에 쓰지 않는다.

## 5. 성공 지표

> CEO 성공 기준(재현율, 수량 오차율, 총액 오차율, UNPRICED 비율, 처리 시간)을 두 단계로 나눈다.
> **합성 단계 지표는 "파서·집계의 자기 일관성"만 보여 준다. 실제 정확도가 아니다(D-004 조건).** 합성 결과만으로 정확도 목표를 확정하거나 Gate 3를 통과시키지 않는다.

### 5.1 합성 단계 (실도면 확보 전, MVP 개발 완료 조건)

| ID | 지표 | 정의 (측정 방법) | 목표 |
|---|---|---|---|
| S-1 | 골든 일치율 | 합성 DXF 세트 전체에서 (품목, 파일)별 수량이 정답과 정확히 같은 셀의 비율 | 100% |
| S-2 | 함정 케이스 커버리지 | F-012 함정 목록 T-01~T-21 중 테스트 케이스가 1개 이상 있고 통과한 비율 | 100% |
| S-3 | 귀속 등식 위반 | 파일마다 "INSERT 총수(전개 후) = 매핑 + 제외(사유별 합) + UNMAPPED"가 성립하지 않는 파일 수 | 0 |
| S-4 | 근거 커버리지 | 품목 수량 합계와 그 품목의 근거 handle 수가 같은 품목의 비율(EA 품목) | 100% |
| S-5 | 경고 재현율 | 합성 도면에 심은 미지원 요소·단위 문제·범례 의심 중 경고로 보고된 비율 | 100% |
| S-6 | 결정성 | 같은 입력, 규칙, 스냅샷으로 2회 실행했을 때 산출물 내용(실행 시각 제외)이 같은지 | 동일 |
| S-7 | 단가 출처 완전성 | 내역서에서 PRICED인 단가 성분 중 D-005(a) 필드 7개가 모두 채워진 비율 | 100% |
| S-8 | 조용한 0 | 출처 없이 0이 들어간 단가·금액 셀 수 | 0 |
| S-9 | 처리 시간 | 합성 대형 파일(INSERT 1만 개 수준)의 실행 시간 | 기록만 한다. 목표는 실도면 단계에서 정한다 |

### 5.2 실도면 단계 (사용자 실도면과 정답 확보 후)

| ID | 지표 | 정의 | 목표 |
|---|---|---|---|
| R-1 | 품목 재현율 | 정답 품목(MVP 공종 범위) 중 우리 결과에 있는 품목의 비율 | 첫 실도면 기준선 측정 후 CEO가 새 D-항목으로 정한다(D-008 Q6). 후보치는 두지 않는다 |
| R-2 | 품목 정밀도 | 우리 결과 품목 중 정답에 있는 품목의 비율 | 동일 |
| R-3 | 품목별 수량 오차율 | 품목마다 \|우리−정답\|/정답. 중앙값과 최댓값을 함께 보고한다 | 동일 |
| R-4 | 수량 완전일치 비율 | 오차 0인 품목의 비율. EA 집계이므로 핵심 지표다 | 동일 |
| R-5 | 초기 UNMAPPED 비율 | 규칙을 수정하기 전, 대상 레이어의 INSERT 중 UNMAPPED 비율. 새 도면 작성자에게 얼마나 잘 맞는지를 본다 | 기록만 한다 |
| R-6 | 매핑 수정 시간 | 담당자가 UNMAPPED를 0으로 만들기까지 걸린 시간. 담당자 보고값 | 기록만 한다 |
| R-7 | 작업 시간 절감 | 같은 도면의 기존 수작업 산출 시간 대비 (도구 실행 + 검토 + 수정) 시간. 담당자 보고값 | 기준선 후 확정 |
| R-8 | UNPRICED 비율 | 내역서 품목 중 재료비, 노무비, 경비 각 성분이 UNPRICED인 비율(성분별) | 기록만 한다. 물가지 구독 판단 자료가 된다(ceo_prompt) |
| R-9 | 총액 오차율 | 정답 내역서 직접공사비 대비. **PRICED 성분이 겹치는 범위에서만** 비교하고 커버리지를 함께 보고한다 | 기준선 후 확정 |
| R-10 | 처리 시간 | 도면 1세트의 실행 시간(검토 시간 제외) | 기준선 후 확정 |

**비교 원칙**: 정답 수량은 순수량이어야 한다. 정답 내역서에 할증이 반영돼 있고 수량산출서가 없으면 R-3, R-4는 산출하지 않고 "비교 불가"로 표시한다. 그래서 사용자에게는 내역서보다 **수량산출서**를 먼저 요청한다.
